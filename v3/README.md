# v3 — 杭州麻将语音播报版

以 v2 为基础，保留座位、发牌、可配置胡法、叠加计分、昵称、截图、全屏和本机牌局存储。当前版本为 `2026-10-17.9-speech`。

用户已取消语音输入和模型纠错，当前网页通过设备系统的 `speechSynthesis` 提供中文语音播报。网页不申请麦克风，不下载模型或推理运行库，也不请求语音识别、纠错或健康检查接口。发牌、胡法和结算均使用原有按钮操作。

## 部署

直接将 `dist/index.html` 覆盖到原麻将网页的静态目录，然后刷新页面即可。无需安装或重启后端；已有服务器上的模型不会被本次文件更新删除。旧版手机缓存保留在原浏览器存储中，新版不会读取或初始化它们。

在开发电脑项目根目录生成单文件：

```sh
npm run build --prefix v3
```

本地开发源码页时可在 `v3` 目录执行 `python3 -m http.server 8080`，访问 `http://localhost:8080/`；构建后的 `dist/index.html` 可直接打开或静态托管。

## 播报内容

- 每局点击确认结算后，自动播报胡牌者、胡法、本局得分、累计分数、下一局庄家和老数。流局也会播报。
- “语音播报”面板支持手动播报累计分数、当前庄家、起牌位置、试听声音、重听上一条和停止。
- 发牌向导保留“播报当前发牌位置”按钮，内容基于当前选择的两颗骰子和真实座位。
- “自动播报每局结算”开关保存在本机，可关闭；手动播报按钮仍可使用。
- 离开页面或关闭播报面板会停止当前播报。不支持语音合成时，显示提示，计分和结果文字继续可用。

手机首次使用可点“试听声音”，确认媒体音量已开启。中文音色和声音服务是否联网由设备系统决定；本次没有实机确认 iPhone Safari 的声音效果，不承诺系统声音完全离线。

## 牌局数据

结算时直接展开全部已启用胡法，分为“常用牌型”“七对系列”“财神与杠”，用标题和浅色底区分。手机宽度足够时使用四列，较窄屏幕使用三列；空间不足时可在结算区域滚动，确认按钮留在底部。已选项显示深绿底和勾选标记，上方实时汇总已选内容及倍率乘积。平胡仍单独计算，其他胡法最多叠加三种；本场禁用的胡法不显示。

v3 使用独立的本机存储键；第一次打开时如存在同源 v2 牌局，会复制快照作为起点，之后各自记录。此次更新不改存储格式，不清空已保存的牌局。v1、v2 源码与构建产物保留。连庄规则包含平庄、一老、二老、三老，庄家倍数依次为 2、4、8、16。

## 源码与发布

- `js/speech.js`：仅提供系统中文语音合成、取消、结束与失败状态。
- `js/voice-app.js`：播报面板、手动朗读与每局结算后的播报内容。
- `js/app.js`：座位、发牌、结算和存储等原有界面流程。
- `scripts/build-single-file.mjs`：仅打包当前页面需要的规则、状态、播报与界面模块。
- `scripts/package-release.mjs`：生成 `release/mahjong-v3-speech.tar.gz`，仅包含静态页面与简短部署说明。

`server/`、`js/local-corrector.js`、`js/model-cache.js`、`js/sensevoice.js`、`js/voice.js` 和 `js/voice-commands.js` 保留为旧实现资料，不进入新版网页或播报发布包。当前无需执行旧的服务器部署、模型下载或 WebGPU 配置步骤。

本轮只生成构建与发布文件，没有新增或运行测试，也未在用户手机上验证实际发声。此前旧语音输入和模型缓存的测试结果不作为当前播报版的验证结果。
