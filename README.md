# 杭州麻将助手

项目按版本目录维护，四个版本均采用静态网页交付。v3 是保留的系统语音播报基线，v4 在此基础上增强麻将馆的趣味风格，使用按钮完成发牌与记分操作。

## 目录

- `v1/`：当前麻将网页的完整保留版本，包含源码、文档和单文件静态构建产物。
- `v2/`：下一版本的独立开发目录，以 v1 当前功能为起点演进。
- `v3/`：以 v2 为基础的播报版本，支持结算自动播报、手动播报分数、庄家与起牌位置。`v3/server/` 保留旧识别服务资料，当前网页不再使用。
- `v4/`：独立的趣味增强版本，加入麻将牌按钮、结算盖章、连庄喝彩和趣味开关。牌局和偏好使用 v4 的独立存储。
- `snapshots/`：v3 基线备份及文件校验清单。
- `docs/`：项目级设计与开发资料。

## 使用

直接用浏览器打开对应版本的 `dist/index.html` 可体验单文件静态页面。v3、v4 都只需部署这一个文件，首次点“试听声音”确认设备可播报即可。v4 建议放在独立的静态目录，例如 `/majiang-v4/`。详情见 [v3 使用说明](v3/README.md) 和 [v4 使用说明](v4/README.md)。修改源码后，在对应版本目录执行：

```sh
npm run build
```

构建结果位于该版本的 `dist/index.html`，可直接打开或部署到任意静态文件托管服务。源码页面 `index.html` 使用 ES modules；本地开发时请通过静态 HTTP 服务器访问。

v1–v3 保留各自已有的 Node.js 测试；v4 首版未新增或运行测试。
