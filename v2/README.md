# v2 — 杭州麻将助手

下一版本的独立开发目录，当前以 v1 的功能为基础。继续采用纯静态交付：可直接打开 `dist/index.html`，源码页面使用 ES modules，本地开发时请通过静态 HTTP 服务器访问。执行 `npm run build` 可生成单文件 `dist/index.html`。

当前能力：骰子点数用数字选择；牌局中可改昵称或生成喜气昵称；牌局设置可启用胡牌方式并调整倍率；胡牌方式可叠加一至三种并相乘；牌局历史可导出 PNG；全屏显示从牌局设置中切换。新增清一色 ×8、十三不靠 ×2、碰碰胡 ×2。换庄时新庄从平庄 ×2 开始，继续坐庄后升为一老 ×4。

v2 的功能改动在本目录内完成，不覆盖 v1 保留版本。
