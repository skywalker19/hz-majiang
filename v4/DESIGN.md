# v4：赏桂品茗国粹馆

## 方向

手机上四个人围桌记分。胡法选择要清楚，确认后用红印章、牌块厚度和连庄喝彩增加趣味。沿用 v3 的真实座位布局、胡法分组及结算顺序。

## 视觉约定

- 桌布绿 `#0b5a4a`、深绿 `#073d35`：牌桌和已选项。
- 牌面白 `#fff9e8`、牌沿色 `#d7c99e`：小麻将牌的顶面与厚度。
- 印泥红 `#d94836`：胡字印章和庄牌。
- 金色 `#f6b943`：连庄升级的短暂强调。
- 展示字用系统楷体 STKaiti/KaiTi；正文用 PingFang SC 等系统无衬线；分数使用等宽数字。无需下载字体或图片。

## 布局

```text
当前局数、庄家和老数       记录 / 改名 / 设置 / 重开
                    牌桌趣味短句
                    上方玩家
        左方玩家      庄      右方玩家
                    下方玩家
          语音播报 / 发牌向导 / 结束本局

确认结算 → 根据特效开关 → 对应档位印章 / 牌匾 + 已保存得分（2.2–3.4 秒）
```

## 动作与内容

- 网页和主屏幕图标采用绿底、象牙白麻将牌及绿色繁体“發”，以路径描绘字形，不依赖设备字体。外框背景铺满方形画布，由手机系统完成主屏幕遮罩；提供 SVG 和 32、180、192、512 像素 PNG。
- 昵称预设分为“杭州地名”“杭州历史名人”两个切换组。地名合并西湖十景、景点、街道；名人涵盖古代至民国的杭州人物及寓杭名人。共 57 项，均不超过四字。折叠面板内先选座位，再选分组与昵称，当前座位、分组和名称高亮，重复项禁用；随机分配只从当前分组抽取四个不同昵称，按钮明确显示地名或名人，整桌保持同系列。打开改名时自动识别现有昵称的统一分组。
- 每条牌局记录并列提供“修改结果”和“导出截图”。编辑复用结算选择，带入原选择，标题明确标注局数，并显示后续重算范围。编辑期间底下的记录面板不可操作。
- 修改只在保存后生效，重算该局及之后的积分和庄家链，局数不增加，当前昵称与头像保留。修改记录有“已修改”标记，结果纠正不播放庆祝特效。
- 内置四男四女共八个卡通矢量头像，以发型、眼镜、服装与底色区分。选择面板按男生、女生分组，每组四列，选中项用绿框和勾选共同标记。
- 开局页与昵称编辑均提供四个座位对应的头像入口；昵称编辑的头像草稿在保存时写入牌局。头像是玩家资料，撤销结算保留当前头像。
- 玩家牌左上角放小圆头像，不挤占名字或分数；头像与庄家标记分列两侧。头像不随趣味特效开关隐藏。
- 胡法按钮有小牌块厚度，选中轻压 2px，并显示“胡”字印章。保留分类颜色、勾选和总倍率。
- 确认结算且牌局保存成功后才显示喝彩。反馈层不拦截触摸，打开下一面板立即收起。
- 特效开启时每次结算播放，关闭后不自动播放，空闲时不弹特效。取消随机出现功能。
- 玩家卡片用单列依次显示座位关系、名字、分数。名字可换行，不截断；分数使用独立行，不与名字争抢横向空间。
- 一老“坐稳了”、二老“手气旺”、三老“出山”。只在真实老数等级提升时使用升级样式；三老后继续连庄沿用三老计分。
- 四档视觉逐级增强：胡牌红印落下；一老翡翠牌匾托起；二老双金环与侧牌；三老红金牌匾、三环与放射金芒。最多 24 个飞牌 / 光点元素；由定时器统一清理。
- 使用不拦截点击的屏幕反馈层，焦点留在原操作位置。牌桌与开局页提供明确标记的预览按钮，预览与记分入口分开。
- 结算后得分轻跳，庄牌短暂强调；历史记录使用小票式虚线。
- “开启特效”控制趣味视觉和播报开场白，两处设置立即同步并保存。语音播报开关单独控制发声。关闭特效后保留普通记分与播报，手动预览仍可使用。
- 尊重系统减少动态效果设置；无闪烁、持续晃动、强制音效或等待倒计时。

## 边界

只用 CSS 和系统语音合成。计分规则与 v3 相同。v4 的牌局、趣味和声音偏好使用独立存储；同源首次访问可复制一次 v3 牌局，此后独立保存。
