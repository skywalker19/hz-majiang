# v4 — 赏桂品茗国粹馆

基于保留的 v3 `2026-10-17.9-speech` 创建，当前版本为 `2026-10-18.7-guocui-hall-v4`。沿用四人座位、发牌向导、全部胡法分组、叠加计分、三摊承包、三老 ×16、牌局记录、截图和系统语音播报。

## 网页与主屏幕图标

- 图标为绿底象牙白麻将牌，正中使用绿色繁体“發”。字形已转为 SVG 路径，设备无需安装字体。
- 浏览器图标使用 `icons/mahjong.svg`，并提供 `icons/favicon-32.png` 回退。
- iPhone 使用 180×180 的 `apple-touch-icon.png`，主屏幕标题为“赏桂品茗国粹馆”。`site.webmanifest` 另提供 192×192、512×512 PNG 图标，路径相对于当前网页目录，可放在 `/majiang/` 等子目录。
- 部署后，在 iPhone Safari 打开网页，点“分享 → 添加到主屏幕 → 添加”。图标支持方式见 [Apple 的配置说明](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)与 [WebKit 主屏幕图标说明](https://webkit.org/blog/13878/)。尚未在目标手机确认实际添加效果。
- 如需修改图案，编辑 `icons/mahjong.svg`，再用安装了 `sharp` 的 Node 环境运行 `npm run icons`。可通过 `MAHJONG_SHARP_MODULE` 指定该模块路径。生成后的 PNG 已包含在源码中，普通构建与发布只复制这些成品，无需安装图像处理依赖。
- 主屏幕只显示首字时，应检查 PNG 响应与 HTTPS 证书信任。公网 IP 的 Docker Certbot 配置材料见 [IP HTTPS 部署说明](deploy/ip-https/README.md)，含挑战路径片段与续期脚本；需要按服务器实际 Nginx 部署方式安装。

## 修改结果

- 打开“记录”，找到填错的一局，点“修改结果”。原胡牌者、胡法、承包者会自动带入，也可在有人胡与流局之间切换。
- 页面使用该局开始时的庄家和老数预览收支，并提示后续受影响的局数；点“保存修改并重新计算”生效，关闭编辑则不保存。
- 从修改局开始顺序重算，更新每局收支、累计分数、庄家和老数；后续各局的胡牌选择、原结算时间、局数与当前昵称、头像保留。直接修改的记录显示“已修改”。
- 新结算保存当局底分、承包开关、全部胡法倍率与启用状态。历史重算沿用各局自己的设置，当前牌局设置不变。旧记录缺少完整设置时，从原计算明细恢复已用胡法倍率与底分，其余胡法沿用当前设置；新增选择前可查看按钮上的倍率。
- 修改结果不触发胡牌庆祝；开启自动播报时，会朗读修改提示、当前累计分数和庄家。原“撤销上一局”入口仍保留。

## 首版趣味效果

- 胡法按钮像小麻将牌，选中时轻压并盖一个“胡”字章；分类颜色、勾选和总倍率继续显示。
- 开启特效时，每次确认结算并保存成功后，显示对应档位特效、胡牌者与实际得分。反馈层不拦截点击，打开下一面板即收起。
- 玩家名字与累计分数各占一行，长名字自动换行；三位数及更长分数不再挤占名字宽度。
- 胡牌：红色“胡”字落印、单环和少量飞牌，约 2.2 秒。
- 一老：翡翠色牌匾托起、绿色光环与飞牌，约 2.6 秒。
- 二老：金色牌匾、双层金环和两侧“连庄”牌，约 3 秒。
- 三老：红金牌匾、三层光环、放射金芒与更多飞牌，约 3.4 秒。
- 一老、二老、三老效果只在实际进入相应等级时播放；三老之后继续连庄沿用三老计分，播放普通胡牌效果。流局使用简短提示。
- 得分数字轻跳，升级后的庄牌短暂强调；牌局记录采用小票虚线。
- 趣味开启时，系统语音在结算结果前加一句喝彩；具体分数仍来自已保存的结算结果。

开局页和“牌局设置”中均保留“开启特效”开关，切换后立即保存在本机，两处控件同步。开启时每次结算都播放，关闭后不自动显示结算画面；不会在空闲时自动弹出。语音播报开关单独控制发声。系统开启减少动态效果时，使用静态反馈。

开局页的“看看胡牌与连庄特效”和牌桌下方的“特效预览”提供四个按钮。预览仅播放视觉效果，不记分、不换庄、不写牌局、不触发语音，也不改变趣味开关；即使关闭自动趣味效果，也可手动预览。

每次最多生成 24 个装饰元素和 3 层光环，播放结束、切换页面或关闭趣味时清理。动画由本地 CSS 和短小的 DOM 操作完成，不下载图片、视频、模型或特效库。

## 打开与部署

直接打开 `dist/index.html` 可使用记分功能。部署时请把 `dist/` 内的全部内容上传到静态目录，例如 `/majiang-v4/`，保持以下结构。本次需要一起上传图标文件，不能只替换 `index.html`。脚本和样式仍内置于网页，无需后端或模型。首次点“试听声音”确认设备音量与中文发声。

```text
index.html
apple-touch-icon.png
site.webmanifest
icons/
  mahjong.svg
  favicon-32.png
  icon-192.png
  icon-512.png
```

在项目根目录构建或打包：

```sh
npm run build --prefix v4
npm run release --prefix v4
```

发布包为 `v4/release/mahjong-v4-fun.tar.gz`，包含网页、图标、manifest 与简短部署说明。源码页面使用 ES modules，可在 `v4` 目录运行 `python3 -m http.server 8080` 后访问。
